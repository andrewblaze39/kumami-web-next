Example

Rachelle wants the Plus delay longer

v1.15In Plus · Flow Radar she changes “delayed 15 minutes” to “delayed 30 minutes”, marks the section (To be developed), and adds to the Release notes: “Plus · Flow Radar: delay 15 → 30 min.”
devAndrew builds it, it’s tested in the browser, and he checks it on the dev site.
v1.20The section now says 30 minutes, without the label. Release notes: “Built from v1.15: Plus · Flow Radar delay is now 30 min.”
Rules
  • One file per version in the shared Drive folder. A version is never edited after it’s shared; fixes go into the next one.
  • The next version takes the next free number. Build versions can skip numbers when there were internal builds in between (v1.15 → v1.20).
  • Build versions describe only what is live. Anything not built is marked (To be developed).
  • Release notes are the change log: one line per change, grouped by product (Basic, Plus, Pro, Payments…).
