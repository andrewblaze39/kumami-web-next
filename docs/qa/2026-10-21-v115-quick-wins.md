## Bugs found and fixed during QA
1. The badge's bell icon rendered page-sized (no SVG size) → sized to 16px; the test now asserts the icon box ≤ 20px.
2. ETF "Today $0" before the daily flow is reported → "Not reported yet".
3. Access-matrix test flake (mobile): it re-wrote `subscriptionStatus = 'cancelled-immediate'`, which the desktop run's "remove Pro" had already stored. Firestore rules only block *changed* fields, so the no-op write returned 200. Not a security hole; the test now writes a fresh value.
