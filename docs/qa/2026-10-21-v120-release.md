## Found and fixed

1. **Cold start under load.** In the first regression run (2 workers, cold caches), 15 tests failed:
   - Watchlist showed "No data";
   - Spot Pulse Pro and Flow Radar timed out.

   With warm caches the same tests passed (81 / 81). Cause: many uncached CoinGlass calls at once queue behind the shared 70 calls/min budget (logged as `[coinglass] 70/min budget full — next call waits Ns`, max 23 s seen). This is real-user relevant only right after caches go cold. The budget now logs long waits, and dropped Watchlist rows are logged instead of vanishing silently.
2. **Gemini free tier.** The key is on Google's free tier: 20 calls/day per model, used up during QA (`RESOURCE_EXHAUSTED`). Every failed call retried on each page view (45 × 429 in one run). Fixes:
   - shared quota cooldown (pauses AI for Google's retry time, max 6 h);
   - default model `gemini-3.5-flash-lite` (own quota; quality checked);
   - Flow Radar sentences cached 30 min per tier + window + verdict + biggest event;
   - empty windows keep the template.

   **Billing must be enabled for production.**
3. **AI wording.** Early sentences repeated "0 events tracked" and claimed "institutions" / "retail" were acting. The prompt now forbids both and names at most one coin.
4. **Hyperliquid "k" symbols** (kPEPE = 1,000 PEPE) now show as the coin itself.
5. **Two test specs** (Spot Pulse, AI layer) had been left uncommitted on their branches. They're now committed.
